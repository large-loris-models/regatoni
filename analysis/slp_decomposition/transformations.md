# T' — Transformation Catalog (Phase 2)

This catalog defines the structural transformations T' extracted by comparing minimal SLP seeds. Each T' is a recipe for adding structure to a base IR. The base shell `define void @f(){ ret void }` reaches 10 / 416 SLP functions; one load+fadd+store reaches 51 / 416. T' adds *kinds* of structure that unlock further functions in the 416 ground truth.

## Coverage signature methodology

For each minimal seed `s`, we computed `Cov(s) = funcs(probe(s)) ∩ 416` and `Uniq(s) = Cov(s) \ ⋃_{t≠s} Cov(t)`. The `Uniq(s)` set names the SLP code paths only that seed reaches; the structure that produces those paths defines a transformation.

## Sharing observations

- **Adjacent load/store** is the workhorse: appears in `T_LS2`, `T_LS4`, `T_LS16`, `T_INTR`, `T_CAST`, `T_COPY`. Most high-coverage seeds are essentially `T_LS{N} ∘ <some op>`.
- **Width parameterization**: `T_LS2`, `T_LS4`, `T_LS16` are the same shape at different N. The 16-wide form does not unlock substantially more 416-functions than the 4-wide form (140 vs 207); coverage scales sublinearly with width once vectorization succeeds.
- **Per-intrinsic delta is small**: ctlz, cttz, copysign all have ≈ identical coverage signatures (123/125/124). Switching one intrinsic for another rarely unlocks a new SLP path; the variability is in the cost model and lowering, not the SLP traversal.
- **The two highest-coverage seeds use neither `T_INTR` nor `T_CAST`**: `compare-node-with-reuses` (241) is `T_CMPSEL` chained, and `copyable_reorder` (207) is `T_LS4 ∘ T_COPY`. The most-rewarding T' for SLP coverage are about the *shape of the dependence graph* (alternates, copyables), not the kinds of operations.
- **Reductions add 9 unique fns over the LS family**, all loop/stride-related (`getLoopNest`, `findInnermostNonInvariantLoop`, `analyzeConstantStrideCandidate`, `isStridedLoad`, `isMaskedLoadCompress`, `vectorizeGEPIndices`, `registerNonVectorizableLoads`, `tryToVectorizeSequence`, `analyzedReductionVals`).
